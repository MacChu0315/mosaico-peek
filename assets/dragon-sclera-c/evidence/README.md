# 参考证据

这些文件来自原上传包的 C 离线工具，使用已选 C 眼白和固定姿态。没有真实热目标输入，没有原生 GSP 或设备录像。

- `poses/contact-sheet.png`：正视、四向、四对角、半闭、全闭，共 11 姿态；每格角色画面为 480×480，标注在画面外。
- `poses/*.png`：各姿态的完整 480×480 单帧。
- `baseline/*.png`：上传包中同姿态的原程序眼白参考，用于比较。
- `sclera-masks/*.png`：上传包给出的各姿态眼白影响区域；只用于差分检查，不是要叠加到设备上的素材层。
- `motion.mp4`：8 秒、480×480、200 帧、25fps、无音频；包含转动和一次完整闭合/睁开。25fps 只表示文件编码设置。
- `input-timeline.csv`：视频逐帧输入；相同参数可以重现相同离线姿态。
- `render.json`、`video-metadata.json`：实际渲染参数与 FFprobe 读取的媒体信息。
- `verification.json`：原程序基线与上传参考一致，交付候选与用户已选 C 静态图一致，全部变化限制在眼白蒙版内，全闭画面不变。

可编辑源的独立读回与合成检查见 `../source/editable-checks.json`。重建入口见 `../preview/DEPENDENCIES.md`。本包保留已有光照、阴影和几何，不把视觉方向选择当成生产工程验收。
