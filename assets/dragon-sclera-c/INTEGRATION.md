# 原生接入说明

## 修改范围

本包只提供现有 dragon 的独立眼白纹理。把它接入虹膜外的巩膜采样分支，其余虹膜、竖瞳、皮肤、眼睑遮挡、球体光照、镜面高光、暗角与姿态变换继续沿用主工程。无需新增眼眶校正层，不使用夜枭/深海交接中的 `rim_restore` 方案。

视觉仍消费主工程既有角色姿态与状态，不自行读取传感器、确认目标、翻转追踪方向或改动检测结果。此素材不新增 IDLE、NOTICE、TRACKING、HOLD、LEAVE、sleeping、waking 的进入规则或时长，也不注册点击、滑动、按住或 AI 按键动作。数据失效、切入切出和全局 UI 切换继续由 main thread 统一处理。

## 纹理与坐标

| 项目 | 约定 |
| --- | --- |
| 文件 | `submission/sclera.png` |
| 尺寸/颜色 | 480×480，RGB8 PNG；整张不透明，无透明洞 |
| 坐标 | 左上原点，x 向右，y 向下；中心 `(240,240)` |
| 球面投影半径 | 233px |
| 虹膜覆盖半径 | `233*26870/32768 ≈ 191.06px` |
| 主要设计区域 | 半径约 191.06–233px 的连续环带；中央与角落也填充材质 |
| 使用空间 | 随眼球转动的平面投影纹理，非固定屏幕层、非经纬度全景图 |

对旋转后的局部球面坐标 `lx/ly`，参考采样为：

```text
u = 240 + lx * 233 / 32768
v = 240 + ly * 233 / 32768
```

几何快照中，球体最终平移到屏幕 `(240,247)`，整体美术倾角约 −0.16 弧度。姿态范围为 `gaze_x∈[-0.78,0.78]`、`gaze_y∈[-0.58,0.58]`，旋转角分别是 `gaze_x*0.83`、`gaze_y*0.72` 弧度。倾角和光照不得再次烘焙进新贴图。美术坐标右/下为正，不表示已完成 MLX90640 物理方向校准。

画序沿用：皮肤/上眼皮底层 → 球面眼白与虹膜、竖瞳及照明 → 开口遮罩、眼睑阴影与高光 → 眼睑边缘、褶皱和暗角。新纹理不能覆盖虹膜分支，也不能在闭眼时穿过眼睑。

## C 参考工具与生产实现的区别

`preview/tool/preview.py` 原样保留输入包工具。它读取原 C 副本，在独立的 `preview/tool/build/` 生成带预览眼白采样钩子的 C 文件并编译；不改 `preview/tool/source/src/dragon_render.c`。钩子只替换虹膜外眼白的程序底色，使用原始 RGB 和双线性采样。它不是已存在的生产纹理 API 或固件资源导入器。

默认 `sample_step=2` 沿用输入包的 240 采样复制为 480 输出；`--sample-step 1` 可用于 480 标量参考检查。不能据此授权其他角色降采样，也不能把离线生成速度当作设备帧率。

参考固定 `squint=.69`、`pupil_width=.072`、`tension=.16`；`blink` 从 0 全开到 1 全闭。8 秒视频使用明确的预设姿态和闭眼曲线，25fps 为文件导出设置。它不运行热目标检测或生产角色状态机，不提供新的状态时长建议。

## 资源与生命周期

PNG 文件实测为 382,300 B。下表仅按像素格式计算一张 480×480 纹理的容量，**不是设备内存或性能实测**：

| 解码/导入格式 | 计算容量 |
| --- | ---: |
| RGB888 | 691,200 B |
| RGBA8888 | 921,600 B |
| RGB565 | 460,800 B |

估算不含解码临时内存、缓存、对齐、DMA、GSP 内部资源或屏幕缓冲。main thread 决定 PNG 解码、预转换、压缩或索引色方案，转换后要重新检查暗绿色层次、纤维细节与 RGB565 舍入。

使用现有 dragon 资源生命周期载入纹理并绑定采样；绘制过程中不逐帧重解码 PNG。切出时按原工程缓存策略归还或保留资源，不停止共享检测器。重新进入直接消费最新共享姿态和状态，不重播确认目标或重置睡眠计时。实际 C 类型、资源所有权及异步载入方式由 main thread 提供，不在本包声明新的公共接口。

## 主工程需要核对

1. 先阅读主工程最新 `AGENTS.md`、`README`、`docs/HANDOFF.md`，确认输入快照的几何、绘制路径和接口仍有效。
2. 将纹理接入原眼白分支，保持所有已认可角色要素；不要以替换整张合成图的方式接入。
3. 对照 `evidence/poses/` 的 11 个姿态、`evidence/sclera-masks/` 的相应眼白蒙版及闭眼帧。已知离线差分都在眼白蒙版内，全闭眼差分为 0；生产格式转换后需再次检查。
4. 在共享 C / 原生 GSP 路径验证采样、色彩和遮挡一致性，再测资源开销、解码/上传时间与帧率；暗部细节可能受实际屏幕和量化影响。

本包没有更改生产资源、共享接口、全局手势、设备配置或依赖，没有操作设备或烧录。原生 GSP、固件实时性能、真实热目标输入及实机视觉仍未验证。
