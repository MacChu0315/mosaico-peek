# 集成说明与边界

## 当前可确认的范围

本包提供三主题位图、参考 JavaScript 模型与离线浏览器预览。主工程的 `AGENTS.md`、`README`、`docs/HANDOFF.md` 以及实际 C/BSP/GSP 接口未提供。本包没有修改主工程，也没有编译、链接、烧录或原生硬件验证记录。

下列字段属于本包 **参考输入契约**，不是已经存在于主工程中的 C 结构体、BSP 事件或 GSP 调用。接入者应先核对实际工程接口，再建立适配层；不能直接根据这里的名字假定项目中存在同名函数。

## 参考输入契约

| 字段 | 参考类型或范围 | 责任与含义 |
|---|---|---|
| `now_ms` | 有限数值，绝对毫秒 | 外部注入的场景时间；模型不自行读取墙钟 |
| `data_valid` | 布尔值 | 当前数据是否可靠；为假不等于明确无目标 |
| `target_confirmed` | 布尔值 | 上游已经确认的目标标志；本包不推导此值 |
| `candidate_present` | 布尔值 | 未确认候选信息；不驱动追视、注意或唤醒 |
| `target_x` | 有限数值，`[-1, 1]` | 归一化水平坐标，右为正；仅有效确认样本可用 |
| `target_y` | 有限数值，`[-1, 1]` | 归一化垂直坐标，下为正；仅有效确认样本可用 |
| `role_state` | 七状态之一 | `IDLE`、`NOTICE`、`TRACKING`、`HOLD`、`LEAVE`、`sleeping`、`waking`；由外部明确提供 |
| `state_entered_ms` | 同一时间基准的绝对毫秒 | 当前状态真正进入的时间；重入时不擅自改成当前时间 |
| `ui_visible` | 布尔值 | 界面是否活动；为假停止界面帧更新并清理局部动作 |
| `theme` | 三主题标识之一 | `night_owl`、`deep_sea` 或 `mechanical` |

业务输入不包含距离、目标分类或新建的检测器状态。候选信息用于预览验证确认边界，不构成确认算法。坐标缺失、非数值或无穷大应进入无效输入分支；有限越界坐标在本包中裁剪至合法范围并带诊断标记；合法的零坐标必须保留。

## 参考模型的防护与诊断

`normalizeSample` 会保留 `coordinates_valid`、`coordinates_clamped`、`target_usable` 和 `role_fallback` 等诊断。无效坐标规范化后的数值占位可能为零，但 **只有 `target_usable` 为真才能将其当作目标**；不能丢掉有效性标记后再把零当作一个新确认目标。

本包的防护默认值如下，目的是让参考预览得到有限、可检查的输出，并不代表主工程的容错策略：

- 无效或负的当前时间使用调用者提供的后备时间；没有后备时间时取零。
- 状态进入时间无效时取当前时间；晚于当前时间时裁到当前时间。
- 未识别的状态回退为 `IDLE`，并置 `role_fallback`；未识别的主题回退为夜枭。
- 数据有效、确认目标、候选三个字段只有严格布尔值 `true` 才为真；可见性只有显式 `false` 才进入隐藏。
- 有限的越界坐标裁剪并置 `coordinates_clamped`；缺失、非数值和无穷大不成为可用目标。

真实适配层应显式提供可靠的时间、状态与可见性，避免把上述默认值误当作业务判断。时间轴采样另将时间限制到所选参考场景的区间内。

## 业务层与显示层的分工

业务层负责真实传感器数据、候选和确认的区分、状态迁移、休眠和唤醒、状态时间、界面可见性以及全局主题选择。显示层只根据当前输入计算注视位移与眼睑闭合度，并将既定图层按顺序绘出。

本包不添加全局输入仲裁器，不接管检测任务，也不通过眼睛画面推断业务状态。失效坐标的 250 ms 保持和 450 ms 归中只是参考显示回退；主工程已有的 `HOLD`、`LEAVE` 或数据失效策略应先被核对。

## 平台能力假设、原生 C 实现思路与轻量替代

下表是 **接入方案建议**。实际平台是否支持这些能力仍须从主工程确认；这里没有虚构 C/BSP/GSP 函数名，也没有交付已编译的原生实现。原生 C 可以保留小型局部状态，消费当前输入快照并计算姿态，再通过工程既有绘制入口提交资源。

| 平台能力假设（待确认） | 原生 C 实现思路 | 轻量替代及取舍 |
|---|---|---|
| 可绘制带 Alpha 的位图，能保持自然尺寸和裁剪原点 | 转换包内 PNG 为项目已有纹理格式；保留画序、Alpha 约定和眼球/眼睑原点 | 若 Alpha 路径不可用，可在桌面端预合成有限状态与注视位置；资源数量增加，连续追视能力降低 |
| 支持位图平移及 480 × 480 输出裁剪 | 将眼球原点加上计算位移，眼睑和前景保持固定；允许负目标原点由输出裁剪处理 | 只使用整数像素位移，或把目标量化为少量位置；不缩放保护区来迁就屏幕尺寸 |
| 可组合相邻眼睑的加权结果 | 按预乘颜色与 Alpha 生成一次混合覆盖，再与眼球合成；可使用项目现有混合能力，也可在 CPU 临时缓冲计算 | 选择最近的九级眼睑之一，省去双眼睑插值及临时混合层，闭合级别会更明显 |
| 已有统一时间、状态快照与 UI 更新入口 | 用普通 C 数据保存当前注视、状态进入时间、失效起点和可见性；从外部时间计算相位，不为每个角色另建计时任务 | 固定更新步长或查表近似 smoothstep；以同一输入与相位规则验收，不能以降低计算量为由自行修改确认/休眠规则 |
| 已有资源与页面生命周期管理 | 当前主题按需保留前景、眼球、当前/下一眼睑；退出时取消角色更新订阅并清理旧过渡，重入从当前输入重建 | 使用一张眼睑和更少的临时缓冲；缓存是否保留由项目内存预算及资源线程规则决定 |
| 已有统一 UI 列表和 BSP 输入分发 | 保留恶龙眼，在主线程列表中追加三款；把一次已经判定的输入动作只提交一次切换 | 优先复用已有手势识别与事件消费机制，不在角色组件中增加第二套全局仲裁器 |

参考 Canvas 使用 `lighter` 将加权预乘分量相加，这只是实现该数学结果的一种方式。**不要求 GSP 存在同名模式或等价命令**；应先核实平台能力，再选择实际混合方法或最近眼睑级别。

### 接入时的资源预算摘要

| 当前主题 | 前景 + 眼球 + 两张眼睑的 RGBA8888 纹理理论量 | 再加一张 RGBA 输出和一张裁剪混合层 |
|---|---:|---:|
| 夜枭 | 2,517,696 字节，约 2.40 MiB | 约 3.79 MiB |
| 深海 | 2,558,196 字节，约 2.44 MiB | 约 3.84 MiB |
| 机械眼 | 2,498,820 字节，约 2.38 MiB | 约 3.76 MiB |

这不是实测预算，也未包含解码器、对齐、上传暂存、双缓冲或队列。中性参考、孔径遮罩、原始大图和闭眼设计源不需要成为设备常驻资源。尺寸、负原点、单眼睑替代量和精确压缩大小见 [视觉规格](VISUAL_SPEC.md)；最终是否适配设备容量需以真实实现测量。

## 生命周期接入

下表区分参考模型行为和实际接入责任。取消原生绘制订阅、释放设备资源或处理 BSP 回调属于后续适配要求，不表示本包中已经存在相应 C 接口。

| 情况 | 适配层需要提供的内容 | 显示层处理 |
|---|---|---|
| 首次显示，已有确认目标 | 当前角色状态、有效坐标、真实状态进入时间 | 按当前相位显示；不统一伪造一次新 `NOTICE` |
| 首次显示，无目标 | 当前无目标信息及当前状态 | 显示相应待机或离开画面，不读取旧目标 |
| 首次显示，已休眠 | `sleeping` 及实际进入时间 | 直接闭眼；候选不能唤醒 |
| 界面隐藏或切出 | `ui_visible=false`，并执行界面退出流程 | 参考模型冻结，角色区域显示黑底；实际适配层应取消角色绘制订阅、清理待执行动作，并按引擎规则处理临时资源 |
| 再次显示 | 最新绝对时间、当前状态和样本 | 重建当前画面，不补播隐藏期间过期的到达 |
| 仅更换主题 | 当前输入与当前状态保持有效 | 使用新主题资源及其位移幅度，避免状态时间被主题变更重置 |
| 时间轴跳转或回放 | 明确的目标时间与场景 | 参考预览从起点确定性重建；不能沿用未来状态的缓存 |

参考播放器在模拟角色隐藏期间仍可推进外部注入时间，便于演示外部状态变化和重新进入；角色模型不继续更新。真正隐藏浏览器标签页时，HTML 工具暂停整个播放器。当前预览没有声称在每次模拟切出时卸载全部图像。

原生端是否保留当前主题纹理、何时释放纹理以及上传线程归属，需要遵循实际引擎生命周期。浏览器的 Canvas、帧请求和临时混合层只说明本包预览的实现，不对应某个已核实的 GSP 资源句柄。

## 全局主题切换建议

主工程现有的 **恶龙眼必须保留**。本包三款是追加到现有 UI 列表中的扩展主题，不能用这三款替换现有注册表。实际列表及顺序由主工程主线程统一确定；若原列表仅含恶龙眼，一种示例顺序是 **恶龙眼 → 夜枭 → 深海 → 机械眼 → 恶龙眼**，相反方向按逆序循环。这个顺序只是示例，不覆盖主工程既有的其他 UI。

| 全局输入 | 建议动作 |
|---|---|
| 左滑 | 下一款 |
| 右滑 | 上一款 |
| 单击 | 下一款 |
| AI 键短按 | 下一款 |

这是一套供主工程核对的统一建议，不是本包已接通的 BSP 事件映射。实际硬件是否产生触摸按下、移动、抬起、手势、单击、短按或长按事件，以及这些事件的先后和消费方式，均待现有 BSP 文档与实现确认。AI 键长按、双击等本包没有新增含义。

**一次滑动只能切换一次。** 当同一触摸序列已被认定为左滑或右滑，应消费该序列，抑制随后可能生成的单击；不能在手势回调和点击回调中各切换一次。去重应放在统一入口或适配层，结合实际事件 ID、触摸序列或取消机制实现，不能假设一个未核实的 BSP 回调名称就能解决。

这一入口应覆盖恶龙眼及新增三款，不允许为某一款眼睛附加“点一下眨眼”“点一下唤醒”等专属行为，也不在角色组件内部再实现一套主题切换。预览只提供显示区域之外的明确按钮与场景控制，没有把本地触摸手势或 AI 快捷键冒充成最终全局规则。

## 参考预览接口

预览采用普通脚本和全局命名空间，便于本地打开。截图与审阅入口为：

```js
await window.previewReady;
const result = await window.setPreviewTime(12000, "night_owl", "full");
```

`setPreviewTime(ms, theme?, scenario?)` 返回 Promise，结果包含 `sample`、`pose`、`state`、`timeMs`、`scenario`、`theme` 与 `render`。它暂停播放并显示指定注入时间；省略主题或场景时使用当前选择。显示画布的元素 ID 为 `screen`。另提供 `setPreviewScenario(scenario, ms=0)` 和 `getPreviewSnapshot()`。

| 参考接口 | 用途 |
|---|---|
| `PreviewTimeline.sampleAt(ms, scenario, theme)` | 从模拟时间线取得输入样本 |
| `PreviewModel.normalizeSample(raw, fallbackNowMs)` | 规范化并诊断输入，不生成确认或业务状态迁移 |
| `PreviewModel.createState(sample)` | 依据当前输入建立可显示状态 |
| `PreviewModel.step(state, sample)` | 以注入的时间推进模型；隐藏状态保持冻结 |
| `PreviewModel.simulateAt(ms, scenario, theme)` | 从场景起点确定性重建至目标时刻，用于跳转、重播和证据 |
| `PreviewModel.sampleAt(ms, scenario, theme)` | 模拟时间线取样的便捷入口 |
| `PreviewRenderer.createRenderer(createCanvas)` | 创建共享 Canvas 渲染器；浏览器和离屏输出注入各自的 Canvas 工厂 |

场景标识为 `full`、`enter_target`、`enter_empty`、`enter_asleep`。模型返回的 `pose` 包含归一化注视、像素注视、眼睑闭合度 `lid`（0 为睁开，1 为全闭）、可见性、参考回退模式及输入诊断。隐藏期间输入时间线仍可表示外部当前状态，而模型姿态保持冻结；因此隐藏样本和旧姿态的时间不同不意味着角色继续更新。渲染器对隐藏姿态只绘黑底。

`preview/assets-data.js` 在本地提供 `window.EYE_ASSETS`，包含三主题的图像数据、`eyeOrigin`/`lidOrigin` 二元素坐标数组和位移上限。预览无需从网络下载图片。`neutral.png` 不作为动态图层加载。参考渲染器接受已解码的眼球、固定前景及九张眼睑；生产端只保留当前/下一张眼睑的按需加载是后续适配建议，当前预览没有声称实现设备纹理流送。

资源的保护覆盖区可能使裁剪图宽度大于 480，或使 `eyeOrigin`/`lidOrigin` 的 X 坐标为负。显示画布仍是 480 × 480；应保留这些自然尺寸和原点，不能把负值钳零或把保护图重新缩放成全屏。

`preview/renderer.js` 与模型都不读取时钟。它将裁剪后的眼球放在 `eyeOrigin + 位移`，将眼睑放在固定 `lidOrigin`，最后绘制全屏前景。相邻眼睑通过临时 Canvas 加权预乘混合；`lowMode` 可选择最近一级眼睑。离屏证据调用同一渲染器，因此画序和插值算法共用；这不等于真实浏览器控件已经验收。

这些都是参考审阅接口，不是产品端 API。原生端应使用实际资源打包流程，不能把浏览器 data URI 容器当作设备纹理格式。
