# 来源、派生关系与授权说明

## 图像来源

本包的三款角色基于会话中已经确认的 **AI 生成原图**：夜枭、深海、机械眼。确认原图的尺寸为 **1254 × 1254 像素**，原始 PNG 按字节保留。原图位于 `originals/night_owl.png`、`originals/deep_sea.png`、`originals/mechanical.png`。尺寸和校验值应结合 `manifest.json` 及包内校验清单查阅；处理后的 480 × 480 资源不能替代原图留存。

闭眼材质来自对相应角色原图进行的 **AI 闭眼派生编辑**。闭眼参考保存在 `design-reference/<主题>_closed_generated.png`，生成提示词、输入原图校验值与生成记录见 `GENERATION.md`。只取闭眼图在眼部孔径内的材质；固定外部前景仍来自已确认原图。它们并非从第三方素材站、字体库或外部图标库取得。本包未引入外部美术资产，也没有打包字体文件。角色位图与设备画面完全不需要字体；证据图像的外部标注字体另见下节。

## 文件类别与派生关系

| 类别 | 来源及处理 | 用途 |
|---|---|---|
| 原始确认图 | 会话中确认的 AI 生成 PNG，字节保持不变 | 来源追溯与原始审阅依据 |
| 闭眼派生原图 | 基于相应确认图的 AI 编辑结果 | 制作闭眼材质的来源；与确认原图分开保存 |
| `processed/<主题>/frame.png` | 原图缩放到目标画布，按孔径分离固定外部结构 | 运行时固定前景 |
| `processed/<主题>/eye.png` | 原图孔径及保护区的透明分层；画布外使用最近的源边缘像素延展 | 运行时眼球位移 |
| `processed/<主题>/lid_00.png` 至 `lid_08.png` | 闭眼派生材质经目标尺寸适配、孔径遮罩和渐进闭合处理 | 运行时九级眼睑覆盖 |
| `processed/<主题>/neutral.png` | 已确认原图的目标尺寸还原 | 对齐和视觉比较 |
| `processed/<主题>/aperture_mask.png` | 为拆层建立的孔径遮罩；以白色 RGB 加覆盖 Alpha 的 RGBA PNG 保存 | 制作、验证与后续转换辅助 |
| 设计参考图 | 从原图或处理后的图层排列、标注或合成 | 视觉评审，不作为设备运行时纹理 |
| 离屏 Canvas 参考截图/视频 | 与 HTML 预览共享的模型及渲染器在模拟输入下的画面记录 | 验证离屏参考画面，不是浏览器控件验收或设备实拍 |

具体路径及文件内容以实际随包文件和 `manifest.json` 为准。相同主题的原图、闭眼派生图和处理后资源应保持对应关系，避免用另一主题的材质补眼睑。

## 字体与工具界面

HTML 预览控件使用系统字体栈，无远程字体请求，也没有附带字体文件。480 × 480 角色画布只绘位图，不包含文字或字体依赖。

离屏证据的画面外英文标注使用制作环境已有的 **DejaVu Sans**，源路径为 `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`。没有将该字体文件打包；其 Bitstream Vera 许可声明保存在 `FONT_LICENSE.txt`，用于说明制作时的字体来源和许可。该字体声明属于第三方材料，不纳入本包原创代码/文档的 MIT 范围。
