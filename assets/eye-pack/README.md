# ESP-Mosaico 三款眼睛界面交接包

这是一份面向 **480 × 480 显示区域**的视觉资源、动效说明和可重复播放的浏览器参考预览。三款扩展主题为 **夜枭**（`night_owl`）、**深海**（`deep_sea`）和 **机械眼**（`mechanical`）。画面内只呈现角色眼部美术；调试数据和预览控件位于显示区域之外。

三款延续现有恶龙眼的单眼近景与强调材质的表现方式。夜枭以铜色圆瞳和羽毛轮廓表现警觉，深海以青蓝横瞳和褶皱软皮表现缓慢关注。机械眼使用琥珀光圈与金属结构，配合较小的追视位移维持机械稳定感。

**本包没有接入主工程，也没有在 ESP-Mosaico 硬件或原生 C/GSP 渲染路径上验证。** 未提供主工程的 `AGENTS.md`、`README`、`docs/HANDOFF.md`、实际状态机、BSP 事件定义或 GSP 接口，因此本包不把任何参考命名、时长、性能估算写成现有工程事实。

## 从这里开始

1. 用桌面浏览器打开 `preview/index.html`。预览使用随包位图和内嵌资源，不需要联网；若浏览器对本地文件施加额外限制，可在本目录启动静态文件服务，再打开同一路径。
2. 先看完整演示，再切换三款主题对比。播放、暂停、拖动时间轴、重播、变速和场景选择都属于预览工具。
3. 对照画面外的输入与状态查看：未确认候选、已确认目标、无效坐标和隐藏界面不会被混为同一件事。
4. 接入前先读 [集成边界](INTEGRATION.md)，再读 [视觉规格](VISUAL_SPEC.md) 和 [动作规格](MOTION_SPEC.md)。资源尺寸、顺序、坐标和精确文件信息以 `assets/manifest.json` 为准。

在本目录提供静态文件服务的一个可选方式是：

```sh
python3 -m http.server 8000
```

随后打开 [本地预览](http://localhost:8000/preview/index.html)。

## 必须保持的行为边界

- **候选目标不等于确认目标。** `candidate_present` 只是输入信息，不可单独驱动追视、到达动作或唤醒。
- 角色状态由外部给定。预览展示 `IDLE`、`NOTICE`、`TRACKING`、`HOLD`、`LEAVE`、`sleeping`、`waking`；不替主工程探测或推导确认状态。
- 只有有效且已确认的目标坐标可作为新的追视依据。坐标缺失或非数值与“明确无目标”分别处理；有限越界值按参考模型裁剪并给出诊断。
- 参考动作使用外部注入的绝对毫秒时间。预览可回放和跳转；隐藏时冻结角色动作，恢复时使用当前状态重新初始化，不补播过期的到达动画。
- 首次进入或重新进入必须覆盖三类情况：当前已有确认目标、当前无目标、当前处于休眠。不能统一重置成一次新到达。
- 保留主工程现有恶龙眼，将三款追加到现有 UI 列表，实际顺序由主工程主线程确定。主题切换建议统一交给主工程的全局入口：左滑下一款、右滑上一款、单击下一款、AI 键短按下一款。识别为滑动后不得再触发一次单击。实际 BSP 事件语义仍需确认。
- 不为某一款角色添加独有的点击动作；预览控件也不构成主工程的全局输入规则实现。

## 完成范围

本包交付三款眼睛的美术拆层、参考动效、独立预览、场景说明和离屏 Canvas 参考证据。每主题提供前景、眼球和九级眼睑，共 **33 张运行 PNG**，另有中性参考、构建遮罩以及保留的 AI 原图和闭眼派生源。

资源检查已确认三主题中性还原的逐通道差为零，三主题共 27 个注视位置采样的合成 Alpha 全为 255；详情见视觉规格和清单。JavaScript 参考模型 **12/12 项检查通过**，包括候选忽略、追视、失效回退、状态所有权、隐藏/重入和确定性回放。证据另含 **21 张七态截图**和 **48 秒、960 帧的三主题演示视频**；20 fps 为离屏导出速率。具体结果及源码校验值见随包验证报告和渲染记录。

HTML 预览没有运行时外部依赖，控件尚未经真实浏览器验收。包内的代码接口是 **参考模型接口**，时长是 **建议参数**。

后续主工程工作仍包括：对照实际工程规则确定状态来源和时序，适配实际 C/BSP/GSP 接口，接入统一切换入口，转换设备资源格式，检查目标设备的显存/内存、帧耗时、颜色和透明边缘，并在硬件上复核隐藏、恢复与输入去重。此处列出的是集成工作范围，不是已完成事项。
