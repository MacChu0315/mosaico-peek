# 深海 R2 · 暗块／回正灰边／瞬膜速度修订

本轮只处理深海，保留R1及夜枭原样。独立审阅稿，没有接入主工程或操作设备。

先打开 `index.html`。重点看：

- `review/deep-sea-r1-vs-r2.mp4`：左R1、右R2，同转动输入，含放慢回正段和瞬膜速度对比。
- `review/surfaces-r1-vs-r2.png`：R1眼球上的眼眶形贴片与R2表面。
- `review/static-r1-vs-r2.png`：正视、四向极限、半膜与全闭的逐对对照。
- `review/return-to-center.png`：R2从gaze_x=0.18回到0，不再出现额外补圈淡入。

## 原因和修改

R1用固定眼眶开口内蚀后的形状来复制原图核心，因此把眼皮投下的明暗也变成了随眼球转动的贴片。回正时，`rim_restore`又按视线位移淡入整圈原图区域，重新带回内缘明暗。用“全正视零像素差”验证时，这种问题反而被当作正确结果保留。

R2不再使用该开口形状来接合眼球。它先以扩展眼球为参考估计原虹膜的低频明暗差异，再做平滑椭圆接合；固定眼眶PNG仍原样保留。绘制路径彻底去掉随视线淡入的rim层，`rim_restore_disabled.png`全透明。

**保留范围需区别说明：** 原瞳孔和近瞳高光的14,589像素仍逐像素不变；周围虹膜进行了明暗匹配与接合，不再声称整张虹膜或整个正视画面零差异。无阴影的完整原虹膜并未恢复，处理是可重复的估计。残余接缝、高光与亮度自然程度仍需要你审阅；若需要精确保留完整原虹膜，应让设计端补无眼眶阴影的完整眼球源。

膜和外眼皮的18张PNG、固定frame与R1逐字节一致；膜仍只来自独立RGBA材质，没有使用整张眼睛参考作为膜。全闭眼图不变。

## 速度

独立瞬膜动作由R1的1,400ms，改为：100ms覆盖 → 20ms停留 → 120ms退回，共240ms。动作总时长约为原来的1/5.8。睡眠闭合仍450ms，醒来仍150ms；只调整膜与外眼皮在该时段内的演示相位。

对照视频12.5秒、60fps。转动范围仍±120/80px；5秒附近专门慢回正；6.3秒和8.1秒开始两次瞬膜对比。视频帧率不是设备帧率；240ms是本轮预览参数，正式接入尚未进行。

## 重复运行

```sh
python3 scripts/revise.py          # 深海静态、图层与检查
python3 scripts/revise.py --movie  # 加上同时间轴R1/R2视频
python3 scripts/package.py         # 本地审阅页、校验与ZIP
```

使用已存在的Python3、Pillow10.4.0、NumPy2.1.1、C11编译器/libm、FFmpeg4.4.2；中文标签使用系统Noto Sans CJK。不安装或升级依赖。

`input/`保留R1只读输入快照（其中夜枭文件只为保留原始记录，本轮不使用）。`scripts/r1_reference.py`是冻结的旧计算参考；`scripts/revise.py`实施本轮修订。参数见 `recipe.json`，新候选图层在 `build/r2/`，原始R1计算结果在 `build/processed/`供比较。构建只写本目录。

`review/validation.json`、`review/independent-review.md`记录实际检查。未做C/GSP接入、传感器输入、设备录像或设备性能验收。主工程保持干净。
