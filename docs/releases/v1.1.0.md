# v1.1.0 — frozen three-eye baseline

User requested freezing the accepted1.0.15-peek-three version as v1.1.0 on
2026-10-25. Firmware identity becomes1.1.0; the local annotated Git tag is
v1.1.0. No behavior, artwork, sensor, control or dependency change accompanies
this release label. Baseline source/record commit4a52dc2.

## Frozen scope

- Dragon with selected sclera C and approved240 sampling.
- Deep-sea R2 with no returning rim and240ms membrane; full480 artwork.
- Mechanical C with socket A and centered sleeping presentation; full480 artwork.
- No night owl resource or selector. Stable UI IDs0/2/3; ID1 rejected.
- Tap/left swipe/AI cycle dragon -> deep_sea -> mechanical; right swipe reverses.
- Shared detection/source processing before display snapshots; no samples in draw.
- Both physical gaze flips enabled; calibrated IMU(-ax,+ay), automatic orientation.
- Existing10s IDLE/450ms close/150ms wake and all detector freshness semantics.
- Pinned dependencies, unchanged partition layout, official System Update only.

The approved baseline's limits are retained: low render FPS may omit some stages
of the240ms membrane; no guarantee every pulse reaches a displayed full-coverage
frame. Physical panel FPS, maximum allocator fragmentation, long-term reliability
and a fresh complete four-placement physical acceptance are not claimed.

## Build and verification

Official release build:

```sh
python3 tools/build_idf.py
```

The wrapper selects isolated build/sdkconfig.v1.1.0 and checks effective version,
startup character, physical mapping, full/detail selections and IMU settings.
Historical build profiles/defaults are not release artifacts. Normal builds
remain source-readonly. Rebuilding later can change timestamps/ELF hashes; this
release freezes the exact verified bundle, not a promise of bit-identical IDF
recompilation. Resource includes and runtime source equality are checked against
1.0.15. The source tag points to the exact commit embedded in the release build;
installation receipts/evidence may be committed afterward without moving it.

## Local release artifacts

The exact official bundle, manifest, allowlisted build configuration, checksums
and installation receipt are retained under releases/v1.1.0/. A local distribution
ZIP includes those files and a source archive of the frozen tag. Build caches,
SDK/dependency copies, full local ELF/map/config backups and .git are excluded.
Exact local ELF/map/config are retained in ignoredfirmware-local/1.1.0/.

Only local commit/tag/artifact creation and the already-authorized same-device
System Update are intended. No remote tag, push, hosted release or default-branch
change. Do not overwrite the release artifact or move v1.1.0. Subsequent visual,
behavior or configuration work must use a new firmware version.

Final artifact identities and actual installation outcome are recorded in the
local release manifest/receipt and current HANDOFF after verification.
