# Owl / sea source recovery intake

The user supplied five original-source ZIPs, preserving the selected night_owl
V5 and deep_sea V3 membrane reference direction. These are explicitly partial
source recovery, not the complete organic-eyes-handoff-v2 delivery.

`assets/organic-eyes-source-recovery/` merges the five ZIPs without changing any
file bytes. It contains10 original1254×1254 PNGs and4 shared documentation files.
All duplicate documents are identical. ZIP CRCs, the manifest/checksum list,
PNG dimensions/modes and source byte counts passed. Exact archive/input hashes
and comparison evidence are in `evidence/organic-eyes/source-intake.json`.

Eight PNGs are RGB; two independent membrane materials are RGBA. Owl alpha
range0..253, sea190..249. The latter is partially transparent throughout, not a
ready-to-use cropped sprite. Original portraits exactly match the two existing
retained eye-pack character originals. No original image was resized/recolored.

Missing from the supplied recovery:

- 42 processed v2 runtime PNGs, including paired eye_surface/rim_restore and
  nine membrane plus nine outer-lid stages per character.
- 4 editable ORA files, deterministic processing scripts and registration/masks.
- v2 preview, simulated input timeline, movies and the claimed verification.json
  and portability-check.json. Their checks cannot be attributed to this recovery.

## Other local artifacts investigated

The downloads folder also contains index.html (6109422B) and
organic-eyes-assets-lite-v1.zip. The HTML embeds42 PNGs, all byte-identical to
the v1 lite package. Its geometry/specs include sphere radius233, sprite origin
(0,128),480×240 overlays and gaze-dependent rim opacity. These can inform a
future reconstruction, but do not establish that the v2 final files survived.

None of the six generated-input hashes in the lite package matches the recovered
10 originals. Its recorded membrane inputs are opaque swatches, while recovery
contains newer separate RGBA membrane originals. Do not silently combine this
older v1 output with the V5/V3 approvals or claim exact v2 restoration.
The local eye-surface-redraw-v2.zip also has no membrane/rim layers and no PNG
hash matches to the recovered source set. No matching final v2 package was
located in the searched project review/download locations.
