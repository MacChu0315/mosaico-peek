当前认可版本：稳定固件 **1.1.1**。仅包含 **怪物眼、深海眼、机械眼**。
先打开 `index.html` 看图和视频，再把 `AGENT_BRIEF.md` 交给负责宣传内容的 agent。

## 哪些能代表当前版本

- 怪物眼：原虹膜和鳞片 + 黑绿纤维眼白 C。静态导出与设备一样使用已认可的240采样、480画布输出。
- 深海：R2眼球表面、当前固定眼眶、独立瞬膜与外眼皮；不使用回正补圈 `rim_restore`。
- 机械：C眼球与中央快门 + 用户选择的旧固定金属眼眶 A；不是 C 原包的新圆形眼眶。
- 夜枭已退役，不在当前宣传角色中。完整帧缓存试验已撤回，不能把它说成当前版本或翻倍提速成果。

## 三种画面的区别

1. 静态 PNG 是生产 C 渲染器的**指定姿态导出**。坐标只用于出图，不是热目标检测结果；不是设备截图。
2. 视频是实际运行原生 C/GSP，使用合成的完整温度数组经过现有检测代码驱动。保留真实截图时间间隔，画布外不含调试控件；不是实机录像。播放／编码帧率不能描述成设备 FPS。
3. `03_device_captures` 是从实际设备读取的帧缓冲截图，没有相机、机身、环境或手与热源。怪物眼截图来自1.0.12历史记录，已认可外观与当前一致；深海和机械来自1.1.1。原始270°方向保持不改，元数据有说明。

所有“可直接使用”图以480×480为准确画布。高分辨率原图是材质／概念来源，不是高分辨率整机或界面截图。不要把拉伸、AI超分或重新生成的图标成实机原始输出。

## 重导出与检查

在完整主工程中：

```sh
cmake --build build-host --target dragon_snapshot eye_snapshot -j4
python3 tools/preview.py --headless --flip-x --flip-y
# 另一终端，在原生预览运行时：
python3 tools/capture_render_trial.py --orientation 0 --output evidence/promo-assets-20261026/native-new
python3 tools/package_promo.py --native evidence/promo-assets-20261026/native-new --output review/promo-new
```

这些命令不连接设备，不修改原素材。打包命令拒绝覆盖已存在的输出目录／ZIP。
解压后可在素材包目录运行 `sha256sum -c SHA256SUMS`。本包不是独立固件构建包，不含SDK、构建缓存、固件二进制或设备运行日志。
