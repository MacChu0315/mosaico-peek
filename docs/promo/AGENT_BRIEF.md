# 给宣传内容 agent 的任务说明

请根据本包准备 Mosaico Peek 的宣传内容草稿，暂不发布。以 `01_ready_to_use` 的当前外观为视觉基准，保持虹膜、瞳孔、眼眶和整体配色；原始图与历史编辑文件只能作为补充来源。

## 项目事实

这是以热成像温度数组驱动眼睛角色的互动演示：共享 C 检测与动作逻辑、原生 GSP 绘制。当前稳定固件1.1.1，角色是怪物眼、深海眼、机械眼。已有发现、跟随、停留、离开、无目标休眠与再次发现后的唤醒表现；触屏点击、左右滑动与 Mosaico AI 键用于角色切换。自动转向保留。

视觉重点可以放在：三种风格、热源驱动的注视、怪物眼的黑绿纤维眼白、深海瞬膜、机械中央快门和闭合居中。这里的“AI键”是设备按键名称，不代表实现了人脸／身份识别。

## 可准备的成果

建议先交可审阅草稿：一张主视觉、三张角色介绍卡、15～30秒短片分镜和配套中文文案。按实际渠道再选横版／竖版／方形比例；保留可编辑文件、引用的素材路径，以及新增背景／特效的说明。

- 先用正视图和原生动作视频选镜头，不要把所有细节堆在同一画面。
- 视频标注“原生界面预览／模拟热源输入”；如另做创意动画，标成设计演绎。
- 如要画设备机身、包装、使用场景或真人互动，当前包没有这些实拍素材，可先留占位并列出需要补拍的镜头。
- 可用高分辨率纹理做背景，但应与当前界面图分开，不能假装是更高清的实机画面。
