# 当前图层与画布说明

设计画布480×480，原点左上，x向右、y向下。静态导出均为正向0°；完整画面是RGB PNG，源图层按原RGBA透明度保留，不把整幅眼睛参考图当透明膜层。

| 角色 | 当前组成 | 位置／画序 |
| --- | --- | --- |
| 怪物眼 | `skin.png`、`iris.png`、`sclera_C.png` | 由生产 C 生成几何、阴影与眼皮；它们不是可按PNG顺序直接叠成完整角色的三层。球面参考中心(240,240)、半径233；角色画布内部另有原有变换 |
| 深海 | `eye_surface.png`、`frame.png`、9级 `membrane`、9级 `lids` | 先转动眼球表面，再叠瞬膜、外眼皮，最后固定前景；膜／眼皮480×240，原点(0,128)。不再叠回正补圈 |
| 机械 | `eye_surface_C.png`、9级 `shutter`、`frame_A.png` | 快门240×240放在眼球贴图(120,125)，先与眼球合成，再一起球面转动，最后叠固定眼眶A。不要把快门固定在屏幕中心 |

位图眼球的纯轴中心摆幅约±120px／±80px，球面半径233。生产 C 参考姿态 gaze_x范围±0.78、gaze_y范围±0.58；这不是像素位移，也不是原始温度传感器坐标。包内极限姿态是出图参考，不是检测到真实目标的证据。

`01_ready_to_use` 每套包含9方向睁眼、全闭及一个中间状态。深海中间状态是独立瞬膜半覆盖、外眼皮打开；机械是中央快门第4档；怪物眼是原有眼皮半闭。怪物眼导出使用源控制器的待机外形参数（squint=.69、pupil_width=.072、tension=.16），仅指定视线和开合；没有改动设备参数。

时间单位为毫秒：深海普通瞬膜100覆盖＋20停留＋120退回；无目标进入IDLE后10秒开始450ms闭合，确认新目标后150ms唤醒。普通眨眼、唤醒和循环应以原生视频及时间线为参考，不要用源素材的旧建议覆盖当前行为。

`05_high_res_sources/deep_sea/membrane_V3_reference_NOT_A_LAYER.png` 含眼球/瞳孔，是外观参考，不是透明瞬膜。真正独立膜图层在 `04_current_layers/deep_sea/membrane`，其1254原始材质是 `membrane_texture_source.png`。

机械原始三态概念图和旧正视图都不是当前完整 UI；现用的是 C 眼球＋A眼眶。可编辑补充包的机械 PSD/ORA 仍包含旧的未采用镜座，请替换为随包 `CURRENT_frame_A.png`，并以主包正视图核对。

深海 R2 未保留完整PSD/ORA：提供当前PNG、蒙版、原图和加工配方。怪物眼 PSD/ORA 仅对应眼白C的1254材质，不能称为全角色分层工程。
