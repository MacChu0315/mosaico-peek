# 三套眼球素材重绘交接：保留摆幅，替换不合格补画

给制作 agent：先读本文，再运行 `python3 check_preview.py --help`。
本任务只制作素材，不修改主工程、不安装依赖到共享环境、不操作设备。

## 已确认与本次目标

用户已确认：原怪物眼左右/上下追踪都正确；新三套的扩大摆动范围合适。
用户明确否决：扩大摆动后新露出的补画区域（俗称“眼白”）太丑。
不要通过缩小摆幅、遮住新区域、放大眼眶或模糊整张图掩盖问题。

请分别为 `night_owl` 夜枭、`deep_sea` 深海、`mechanical` 机械制作完整眼球材质。
这不是重做整个480画面：只重画原来隐藏、转动后会露出的眼球表面。
原虹膜、瞳孔、正视画面、眼眶、羽毛/皮肤/金属前景和九层眼睑保留。
可以由不同 agent 各做一个主题，输出契约完全相同。

- 夜枭：延续获选原图的铜色圆瞳与整体色调。新增眼球表面应自然衔接，
  不应出现复制羽毛、眼眶边缘或整条横向拉伸纹理。
- 深海：延续青蓝横瞳和既有材质。转动后不要暴露整块无细节填色、
  镜像条纹或从原图复制过来的外层褶皱/遮挡边缘。
- 机械：延续琥珀光圈、机械结构和光照；新露出的表面应是有连续结构的
  完整球体/机械眼内部，不要把固定外壳或眼睑画进转动贴图。

“眼白”只是用户对新增区域的称呼，不要求画成人类的白色巩膜。
三套可各自处理材质；必须遵循原图的色彩、光照和结构连续性。
允许使用生成模型、数字绘画或其他素材工具；务必留源文件、来源和制作记录。

## 制作与检查

先将作品放到 `submission/<theme>/eye_surface.png`。对单主题可以只提交该主题。
依赖参考：Python3.10、Pillow10.4.0、NumPy2.1.1；可选 FFmpeg4.4.2。
使用制作 agent 自己的隔离环境，不升级主工程共享工具链。

```
python3 check_preview.py --input submission --output proof
python3 check_preview.py --input submission --output proof --theme mechanical --animate
```

复现“尺寸和遮罩合格，但艺术效果不合格”的反例：

```
python3 check_preview.py --input rejected --output rejected-proof --animate
```

脚本检查参考文件完整性、尺寸、alpha、锁定区逐像素一致；输出九宫格、
各方向全分辨率PNG、半闭/闭眼图及 JSON 报告。`--animate` 用直接指定的
动作参数输出8秒/12fps材质检查视频（四向+斜向+眨眼）。这是模拟动作参考，
不是温度检测、实机录像或设备FPS。Python渲染与原生C在RGB565舍入边界上
可能差1个通道码；主工程接入时仍需原生逐像素和设备验证。

请重点看极端四向、四个对角、半闭眼和从正视进入新纹理的连续过程。
不要仅看九宫格中央。技术检查通过不等于视觉验收通过；脚本始终不授予
`visual_approved`。被否决的自动补画也能通过这些技术检查。

推荐先完成一套、检查全角度再复制方法到其他主题。若锁定正视区与新材质
接缝无法消除，请返回清楚标注的备选方案和差异，不能自行改锁定区。

## 交回主工程 agent

每套返回：

1. `submission/<theme>/eye_surface.png`；可同时给可编辑PSD/KRA/SVG等源文件。
2. `SOURCES.md`：原图引用、使用工具/模型与版本、素材来源/授权说明、是否
   生成式制作、加工步骤；不要把AI生成素材虚构成第三方商用许可。
3. `proof/` 的九宫格、关键角度和8秒预览，保留真实设计时长，不宣传设备FPS。
4. `CHANGES.md`：改了哪些可编辑区域、接缝处理、已知缺陷，注明未改锁定区。
5. 作品SHA256清单，打成一个小ZIP；不要带依赖、缓存或整个工程。

主工程收到后会新增独立素材目录并记录来源，保留本交接和原包；再完成
构建器适配、共享 C/原生 GSP 比对、固件资源/性能和实机检查。本交接不表示
已有通用角色导入器，也不把Python预览称为设备接入完成。
