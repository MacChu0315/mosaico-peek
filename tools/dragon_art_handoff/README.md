# 第一幅怪物眼：眼白素材优化交接

## 任务边界

只优化第一幅怪物眼（dragon）的眼白/巩膜。保留当前虹膜、竖瞳、紫黑鳞片、厚眼睑、转动范围和闭眼造型。不要改其他三个角色，不要修改检测、追踪方向、动作时序或设备工程；返回素材后由主线程适配生产 C/GSP 并验证。

**当前没有独立“眼白原图”**：`source/src/dragon_render.c` 的 `eyeball()` 在虹膜外用基础 RGB(49,63,23) 和正弦纹理生成眼白，然后叠加球体照明、眼睑阴影和高光。`template/current-procedural-sclera.png` 是这段程序导出的、未加照明的可编辑参考，不是获选原图，也不是用户认可的新设计。

先看 `reference/contact-sheet.png`，再看 `reference/motion.mp4`。前者是当前生产 C 的姿态参考；后者是明确标注的 8 秒预设动作测试，不是实时热源输入或实机录像。`original-reference/` 中两段旧视频是原始离线设计参考，也不是实机性能证据。

## 新素材规格

返回 `submission/sclera.png`：**480×480，PNG，RGB 或完全不透明 RGBA**。保留高质量可编辑源（PSD/ORA/矢量或分层PNG）、提示词/来源/工具版本、加工步骤和哈希。不要覆盖本包参考文件。

这是**随眼球转动的平面投影纹理**，不是屏幕固定“眼白”，也不是经纬度全景图。纹理中心(240,240)，半径233；x向右、y向下。虹膜半径 `233*26870/32768 ≈ 191.06`，中央区域由现有虹膜和瞳孔遮住。眼白采样坐标为 `u=240+lx*233/32768`、`v=240+ly*233/32768`，其中lx/ly是旋转后的局部球面坐标。

请把整张图填满、不留透明洞；重点设计虹膜边缘到球面边缘的连续环带，兼顾四向/斜向极限。中央被覆盖区可以延续底色。不要把虹膜、竖瞳、外部鳞片、眼睑、固定高光、深黑眼睑投影画进眼白。柔和色彩和细节可以存在，但球体明暗/镜面光主要由现有渲染器叠加，避免双重照明。

当前整体画布480×480；球体的本地原点最终平移到屏幕(240,247)，整体带约-0.16弧度美术倾角。参考工具已使用原有变换，不要把该倾角再画进新贴图。

画序：皮肤/上眼皮底层 → 球面（眼白与虹膜分区、竖瞳、球体照明）→ 开口遮罩/眼睑阴影/高光 → 上下眼睑边缘/褶皱/暗角。眼白在虹膜外，受到眼睑遮挡。闭眼时不能露出新眼白。

## 可运行预览

预览工具只在本包 `build/`、指定输出目录生成文件，不改任何参考源。Python3 + **Pillow10.4.0**、C11编译器和系统libm；生成视频还需FFmpeg。本包实际验证版本见 `VALIDATION.json`。没有固件、SDK或共享依赖副本。

```sh
# 生成当前生产 C 的基线（不载入新眼白）
python3 preview.py --output my-baseline --movie

# 预览你的新眼白；除眼白采样外保留同一 C 绘制过程
python3 preview.py --surface submission/sclera.png --output my-proposal --movie
```

默认采用设备已认可的240采样复制到480输出；`--sample-step 1` 可检查480标量参考。不要据此授权其他角色降采样。新贴图的参考采样使用原始RGB和双线性插值，**还不是生产资源编码方案**；主线程之后决定纹理格式、缓存和性能，不能称“已接入原生GSP/设备”。工具拒绝非480尺寸或任何非不透明像素。

测试参数：`gaze_x∈[-0.78,0.78]`、`gaze_y∈[-0.58,0.58]`；右/下为正。这是美术坐标，不是 MLX90640 原始物理坐标，不要自行翻转。球面旋转角分别为 `gaze_x*0.83`、`gaze_y*0.72`（弧度）。`blink∈[0,1]`，0全开、1全闭；其他参数固定 `squint=.69,pupil_width=.072,tension=.16` 以便可比。工具内姿态清单和动画曲线可查阅，不代表生产状态机。

`motion.mp4` 为单段8秒、25fps导出：前5秒平滑遍历正视/四向/对角/回中，随后闭合、停留、再睁开回到起点。时间单位秒，线性插值外套smoothstep，首尾一致，可循环播放。时长保持真实设计时间；25fps不是实机帧率。原始 `timeline.mjs` 也以秒为单位，但仅为历史动作参考。当前生产休眠是IDLE10秒后450ms闭合，确认新热目标后150ms唤醒；此次不修改这些规则。
